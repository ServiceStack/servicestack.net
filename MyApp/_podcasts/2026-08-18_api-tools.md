**ServiceStack API Tools** allow developers to transform their existing .NET web services into intelligent capabilities that **AI models** can understand and use. This system eliminates the need for manual prompt engineering or duplicate schemas by using **live API metadata** as the single source of truth for discovery and execution. 

Integration is managed through three core tools—**search, describe, and call**—which enable assistants to find relevant functionality and execute tasks securely. 

The platform features a built-in **AI Chat interface** and supports the **Model Context Protocol (MCP)**, allowing external assistants like Claude or Cursor to interact with the system. 

Security is maintained by ensuring the AI acts as an **authenticated user**, respecting all existing authorization rules and requiring **human approval** for destructive actions. 

This approach simplifies the creation of AI-powered applications by turning standard APIs into a **discoverable capability layer** for various natural language workflows.
