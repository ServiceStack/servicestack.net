The **AI Chat** feature for .NET applications integrates a ChatGPT-like assistant directly into existing software platforms to streamline data analysis and reporting. 

Operating securely within the application's **authenticated user permissions**, the assistant dynamically discovers and queries live APIs without requiring a separate backend infrastructure. 

Users can prompt the system to generate complex, interactive visualizations and comprehensive business documents, such as **3D customer galaxies** or **monthly leadership slide decks**. 

To maintain strict data governance, **read-only operations** execute immediately while write actions require mandatory human approval through an editable form. 

Furthermore, generated artifacts remain in a private workspace until a user chooses to **explicitly publish** them, ensuring that sensitive information stays protected behind proper security boundaries.
