**AI Chat** puts a ChatGPT-like assistant inside your .NET App. It runs as the signed-in user, so it can only see what they can. With **API Tools** it discovers and calls the APIs you've opted in, through the same validation, authorization and capability checks as the rest of your App. There's no parallel AI backend to build, as your existing Request DTOs are the AI contract. Reads run immediately, while writes pause for an editable approval form so a person decides every change.

**Projects** give the assistant a private workspace for turning API results into more than a paragraph of chat. In the **Next SaaS** template, one prompt builds an interactive 3D **Customer Galaxy** that ranks the revenue at risk, and another writes a ten-slide **Monthly Business Review** with a retention worklist and prioritized recommendations. Both can be previewed in chat, then published as a static site with an explicit **Share → Folder** step, which you run again to publish later changes.
