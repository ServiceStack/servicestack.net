Add ServiceStack Reference now generates end-to-end typed API integrations for **15 of the world's most popular programming languages** with first-class support for **Go, Rust, Ruby and Zig** - spanning .NET, web and scripting, mobile, and now cloud and systems software. Each language gets clean native DTOs and an idiomatic Service Client that understands the API contract: response types, HTTP methods, routes, authentication, structured errors, validation failures and AutoQuery conventions.

Every client uses its language's standard library with no third-party runtime dependencies, whilst staying idiomatic - Go returns values and errors, Rust offers async and blocking clients, Ruby uses natural constructors and exceptions, and Zig makes allocation and cleanup explicit. Generate DTOs for any running API with `npx get-dtos <language> https://your-app.example.com`.
